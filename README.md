# Oksanium (OXN)

> Символический цифровой токен проекта. Дата рождения: 25.11.2026.
>
> **Посвящается Оксане.** Создан в честь её дня рождения.

## Что это

Oksanium — персональный токен, рождённый как подарок. Идея проекта принадлежит Вадиму (@pentium323-lang).

План развития:
- **Этап 1 — «Энергия»:** внутренняя учётная единица экосистемы проекта (баланс, активность, обмены между сервисами проекта).
- **Этап 2 — Выпуск в блокчейне TON:** jetton по стандарту TEP-74 — реальный цифровой актив с адресом в блокчейне, видимый в кошельках Telegram.
- **Этап 3 — Экосистема:** использование токена в сервисах и мини-приложениях для пользователей.
