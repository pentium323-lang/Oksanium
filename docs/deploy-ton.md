# Инструкция выпуска Oxanium на TON

Пошаговый выпуск jetton Oxanium через кошелёк Telegram. Все транзакции подписывает владелец кошелька — выпуск personalный.

## Что нужно

- Кошелёк **Telegram Wallet** (или Tonkeeper / TON-кошелёк на выбор).
- Небольшой запас TON на комиссию: **1 TON достаточно с запасом** (реальный расход на выпуск jetton — сотые доли TON).
- Ссылка на логотип токена (image-URL) — берётся из файлов этого репозитория.

## Шаги

1. Открой **https://minter.ton.org** — официальный генератор jettons TON.
2. Подключи кошелёк (Wallet Connect / Tonkeeper).
3. Выбери «Deploy Jetton» и заполни поля:

   | Поле | Значение |
   |---|---|
   | Name | `Oxanium` |
   | Symbol | `OXN` |
   | Decimals | `9` |
   | Total supply | по выбранному варианту из [tokenomics](tokenomics.md) (например `2511260000`) |
   | Image | URL логотипа из репозитория |

4. Подпиши транзакцию деплоя в кошельке (комиссия — копейки в TON).
5. **Сразу после выпуска:** скопируй адрес jetton master и запиши его в этот репозиторий (раздел ниже) — это «свидетельство о рождении» токена.

## После выпуска (чек-лист)

- [ ] Адрес jetton master вписан в этот документ
- [ ] Токен открывается в Tonscan (по адресу)
- [ ] Появился в списке активов Telegram Wallet
- [ ] Отправлен тестовый перевод между своими кошельками

## Адрес jetton master

> Заполняется после деплоя.

## Примечание по безопасности

- Сид-фразу кошелька никому не сообщать, не фотографировать, не хранить в облаке.
- Деплой выполнять только с официального сайта minter.ton.org, сверяя адрес в адресной строке.
- Для пробного выпуска сначала можно использовать тестовую сеть TON Testnet — всё то же самое, но бесплатно.
